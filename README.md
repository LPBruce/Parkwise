# Parkwise · 停车练习场

双击 `index.html` 即可在现代浏览器中打开，无需安装依赖或启动服务器。

- W / ↑ 前进，S / ↓ 倒车；A / ← 和 D / → 控制前轮。
- 空格刹车，Esc 暂停，R 重置。触屏可使用页面底部按钮。
- 选择场景或难度会立即重新开始；碰撞后可反向驶离。
- 白色车辆的白色灯带一端为车头；绿色虚线是停车或驶出目标区域。

车辆使用简化低速自行车模型；场景尺寸是示意，双线预测车身前沿或后沿两侧在保持当前转向时的近似路径，不能替代实车观察。

车辆外形参考理想 i6 的白色车身、深色车顶及贯穿式灯带，模型尺寸采用约 4.95 × 1.935 米、轴距 3 米；造型和运动均为简化模拟。
